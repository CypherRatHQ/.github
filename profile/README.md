## Hintbeam

**[Hintbeam](https://github.com/CypherRatHQ/hintbeam)** adds product tours to React, Next.js and React Native apps. Tours point at named targets instead of CSS selectors, follow users across pages, and are typed data. MIT licensed.

```sh
npm i hintbeam
```

[Docs](https://hintbeam.js.org) · [Getting started](https://hintbeam.js.org/docs/getting-started) · [Playground](https://hintbeam.js.org/playground) · [npm](https://www.npmjs.com/package/hintbeam)
